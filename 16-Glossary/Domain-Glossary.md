# Domain Glossary

## Istilah bisnis

- Account: cabang/akun operasional yang memiliki admin dan lead.
- Admin: user operasional cabang yang mengelola lead.
- Super Admin: user pusat dengan akses penuh.
- Lead / Consultation: data prospek/konsultasi customer.
- Needs Category: kategori kebutuhan/produk customer.
- Status Category: tahap pipeline lead.
- Reminder: pengingat follow-up lead.
- Consultation Note: catatan timeline follow-up.
- Survey: proses kunjungan/pengecekan lokasi dari lead.
- Surveyor: user yang mengerjakan survey.
- Manager Surveyor: user yang menjadwalkan dan mengelola survey.
- Survey Status: status hasil survey, berbeda dari state workflow survey.
- Report Attendance: laporan/absensi harian admin.
- Audit Log: catatan aktivitas/perubahan penting.
- Bug Report: laporan bug dari user.
- Wilayah: data geografis provinsi/kota/kecamatan.

## Istilah teknis

- MOC: Map of Content, halaman indeks penghubung catatan Obsidian.
- Query key: identifier cache TanStack Query.
- Invalidation: proses refresh cache setelah mutation.
- Policy: kelas Laravel untuk authorization object.
- Middleware role: guard route berdasarkan role user.
- Queue worker: proses background untuk import atau pekerjaan async.
