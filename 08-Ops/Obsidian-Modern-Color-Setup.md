# Obsidian Modern Color Setup

CSS modern vault sudah aktif lewat snippet `e-report-vault-colors`.

## Jika graph masih semua biru

Obsidian sedang terbuka dapat menulis ulang `.obsidian/graph.json`. Preset warna modern disimpan di:

`E-REPORT-APP/.obsidian/graph-modern-preset.json`

Langkah apply:

1. Tutup Obsidian.
2. Salin isi `graph-modern-preset.json` ke `.obsidian/graph.json`.
3. Buka Obsidian lagi.

## Palette domain

- Architecture: violet
- Backend/Internal: emerald
- Frontend/UI: cyan
- Database: orange
- API: blue
- Modules/Workflows: teal
- Ops/Testing: lime
- Decisions/Change Log: gold
- Security: clean red
- Glossary: slate
- Hub nodes: white
